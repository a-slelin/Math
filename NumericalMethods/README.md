# Численные методы 🔢

В данном подпроекте собраны лабораторные работы по курсу "Численные методы". Все программы написаны на **Python**
максимально простым языком, чтобы их было легко читать и объяснять; графики строятся с помощью **matplotlib**.

## Структура 📁

* **Lab1**: решение линейных интегральных уравнений (метод последовательных приближений, сведение к СЛАУ, аналитическое решение);
* **Lab2**: лабораторная работа №2;
* **Lab3**: лабораторная работа №3;
* **Lab4**: лабораторная работа №4.

Каждая лабораторная работа устроена одинаково:

* **README.md**: условие задачи и описание решения;
* **python/src/main**: программа на Python;
* **results**: результаты (графики, таблицы).

## Запуск 🚀

Перед запуском нужно настроить окружение (см. корневой **README.md**), после чего:

```shell
# Подставить номер нужной лабораторной работы вместо Lab1;
python NumericalMethods/Lab1/python/src/main/main.py;
```
