# Информационная безопасность 🔐

В данном подпроекте собраны лабораторные работы по дисциплине "Информационная безопасность". Задания и варианты
выдавал преподаватель; условие каждой работы лежит в папке **util** соответствующего модуля.

## Структура 📁

* **Substitution**: классические шифры замены (Цезаря, Тритемиуса и Вижинера);
* **Analytic**: шифрование аналитическими преобразованиями — умножение матрицы-ключа на векторы из номеров букв
  (определитель, обратная матрица, генератор ключей с det = ±1).
