# Шифры замены 🔑

Лабораторная работа №1 "Использование методов замены для шифрования данных" ([**условие**](util/Task.pdf)),
вариант **2**.

## О чём?

Реализуются три классических шифра замены над русским алфавитом из 32 букв (без «Ё», буквы **Ь, Ы, Ъ** стоят в конце):

* **Цезаря**: каждая буква сдвигается на фиксированное число позиций: l = (m + s) mod 32;
* **Тритемиуса**: сдвиг для каждой буквы свой и задаётся словом-ключом: l = (m + k) mod 32;
* **Вижинера**: шифрование выполняется через построение таблицы Вижинера 32×32 и рабочей матрицы для ключа.

Дополнительное задание: режим, который строит и выводит таблицу Вижинера 32×32 и рабочую матрицу для произвольного
ключа (в консоль и, по желанию, в файл **vigenere_table.txt**).

## Структура 📁

* **Main**: консольный интерфейс (меню, ввод данных, вывод результата);
* **Algorithm**: функции шифров `caesar`, `trithemius` и `vigenere` (шифрование и расшифровка);
* **Util**: вспомогательные функции (алфавит, подготовка текста, таблица Вижинера, группы по 5 знаков);
* **BasicTest**: тестовые данные для самопроверки из пункта 4.4 и проверка требований пункта 4.1;
* **CheckTest**: проверка ручного решения (часть А) для варианта 2.

## Запуск 🚀

```shell
# Собираем .jar-файл и прогоняем тесты;
mvn clean package;

# Запускаем .jar-файл на исполнение;
java -jar target\Substitution.jar;
```

Если в консоли Windows русские буквы отображаются неверно, переключите её на UTF-8 командой `chcp 65001`.
