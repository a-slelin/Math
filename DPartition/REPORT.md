# Отчёт: D-разбиение для характеристического уравнения (вариант 17) 📝

## 1. Постановка задачи

Рассматривается характеристический квазиполином

```math
P(\lambda) = \varepsilon^2\lambda^2 + \varepsilon A\lambda + 1 + a_1 e^{-2\lambda} + a_2 e^{-6\lambda},
\qquad 0 \le \varepsilon \le 1.
```

Запись $`e^{-\lambda 2}`$, $`e^{-\lambda 6}`$ из условия понимаем как $`e^{-2\lambda}`$, $`e^{-6\lambda}`$, т.е. запаздывания
$`\tau_1 = 2`$, $`\tau_2 = 6`$ (как и в соседних вариантах: $`e^{-\lambda}`$, $`e^{-\lambda 3}`$ и т.д.).

Такой квазиполином возникает, например, у линейного уравнения

```math
\varepsilon^2 \ddot x + \varepsilon A \dot x + x + a_1 x(t - 2) + a_2 x(t - 6) = 0
```

при подстановке $`x = e^{\lambda t}`$. Нулевое решение асимптотически устойчиво, если **все** корни $`P(\lambda)`$
лежат в левой полуплоскости $`\mathrm{Re}\,\lambda < 0`$.

**Цель:** при фиксированных $`\varepsilon`$ и $`A`$ разбить плоскость параметров $`(a_1, a_2)`$ на области с одинаковым
числом $`N`$ корней в правой полуплоскости (D-разбиение) и найти область устойчивости $`N = 0`$.

По умолчанию берём $`A = 1`$ и $`\varepsilon = 0.5`$; дополнительно разбираем $`\varepsilon = 1`$ и поведение при
$`\varepsilon \to 0`$. Все параметры меняются в `const.py` или аргументами командной строки.

## 2. Идея метода D-разбиения

1. При $`\varepsilon > 0`$ старший член $`\varepsilon^2\lambda^2`$ не содержит запаздывания — квазиполином
   **запаздывающего типа**. У него в любой правой полуплоскости $`\mathrm{Re}\,\lambda \ge -c`$ лишь конечное число
   корней, и корни не могут «прийти из бесконечности» в правую полуплоскость.
2. Корни непрерывно зависят от $`(a_1, a_2)`$. Значит, число $`N`$ корней с $`\mathrm{Re}\,\lambda > 0`$ может
   измениться только тогда, когда какой-то корень **пересекает мнимую ось**.
3. Поэтому границы областей D-разбиения — это множества параметров, при которых $`P`$ имеет корень
   $`\lambda = 0`$ или $`\lambda = \pm i\omega`$, $`\omega > 0`$.
4. Внутри каждой области $`N`$ постоянно; достаточно знать $`N`$ в одной точке и правило изменения $`N`$ при переходе
   через границу (штриховку).

## 3. Граница $`\lambda = 0`$

```math
P(0) = 1 + a_1 + a_2 = 0 \quad\Longleftrightarrow\quad a_2 = -1 - a_1.
```

Это прямая. При $`1 + a_1 + a_2 < 0`$ имеем $`P(0) < 0`$, а $`P(\lambda) \to +\infty`$ при $`\lambda \to +\infty`$, поэтому
у $`P`$ появляется положительный вещественный корень. Переход через прямую в сторону $`1 + a_1 + a_2 < 0`$
**увеличивает $`N`$ на 1** — эту сторону и штрихуем.

## 4. Граница $`\lambda = i\omega`$ (D-кривая)

Подставим $`\lambda = i\omega`$, $`\omega > 0`$ (корни вещественного квазиполинома сопряжены, так что $`\omega < 0`$
даёт ту же кривую):

```math
-\varepsilon^2\omega^2 + i\varepsilon A\omega + 1 + a_1(\cos 2\omega - i\sin 2\omega) + a_2(\cos 6\omega - i \sin 6\omega) = 0.
```

Отделяя вещественную и мнимую части, получаем **линейную** по $`(a_1, a_2)`$ систему:

```math
\begin{cases}
a_1\cos 2\omega + a_2\cos 6\omega = \varepsilon^2\omega^2 - 1 =: R(\omega),\\[2pt]
a_1\sin 2\omega + a_2\sin 6\omega = \varepsilon A\omega =: I(\omega).
\end{cases}
```

Её определитель

```math
\Delta(\omega) = \cos 2\omega \sin 6\omega - \sin 2\omega \cos 6\omega = \sin 4\omega .
```

По правилу Крамера при $`\sin 4\omega \ne 0`$:

```math
\boxed{\;
a_1(\omega) = \frac{R\sin 6\omega - I\cos 6\omega}{\sin 4\omega},\qquad
a_2(\omega) = \frac{I\cos 2\omega - R\sin 2\omega}{\sin 4\omega}
\;}
```

Это параметрическое уравнение D-кривой (функция `d_curve` в `equation.py`).

### 4.1. Ветви и особые точки

В точках $`\omega_k = k\pi/4`$ определитель $`\sin 4\omega`$ обращается в ноль, и кривая уходит на бесконечность.
Поэтому D-кривая состоит из ветвей на интервалах $`\left(\tfrac{k\pi}{4}, \tfrac{(k+1)\pi}{4}\right)`$
(функция `d_curve_branches`).

Если в особой точке система **совместна**, она задаёт целую прямую (особую прямую D-разбиения).
Разберём чётные и нечётные $`k`$ отдельно.

#### Чётные $`k = 2m`$, $`m \ge 1`$

Здесь $`\omega = \pi m/2`$, $`\sin 2\omega = \sin 6\omega = 0`$, $`\cos 2\omega = \cos 6\omega = (-1)^m`$, и система
принимает вид

```math
(-1)^m(a_1 + a_2) = \varepsilon^2\omega^2 - 1, \qquad 0 = \varepsilon A\omega .
```

Второе уравнение совместно только при $`\varepsilon A = 0`$. При $`\varepsilon A \ne 0`$ особых прямых этого типа нет.

**Случай $`A = 0`$, $`\varepsilon \ne 0`$.** При каждом $`m \ge 1`$ получаем особую прямую (корни $`\lambda = \pm i\pi m/2`$):

```math
a_1 + a_2 = (-1)^m\left(\frac{\varepsilon^2 m^2\pi^2}{4} - 1\right).
```

Например, при $`\varepsilon = 0.5`$ в окно попадают прямые $`a_1 + a_2 \approx 0.383`$ ($`m = 1`$) и
$`a_1 + a_2 \approx 1.467`$ ($`m = 2`$).

**Случай $`\varepsilon = 0`$ (при любом $`A`$).** Получаем $`(-1)^m(a_1 + a_2) = -1`$, то есть:

* при чётном $`m`$ — прямая $`a_1 + a_2 = -1`$. Она **совпадает** с границей $`\lambda = 0`$: на ней одновременно есть
  корни $`\lambda = 0`$ и $`\lambda = \pm i\pi m/2`$, потому что при $`\varepsilon = 0`$ уравнение зависит только от
  $`z = e^{-2\lambda}`$, а все эти $`\lambda`$ дают $`z = 1`$;
* при нечётном $`m`$ — новая особая прямая $`a_1 + a_2 = 1`$ (корни $`\lambda = \pm i\pi m/2`$, им отвечает $`z = -1`$).

#### Нечётные $`k = 2m+1`$

Здесь $`\omega = \pi(2m+1)/4`$ и $`\cos 2\omega = \cos 6\omega = 0`$. Первое уравнение даёт $`\varepsilon^2\omega^2 = 1`$,
то есть

```math
\varepsilon = \frac{4}{\pi(2m+1)} .
```

На отрезке $`[0, 1]`$ это $`\varepsilon \approx 0.4244;\ 0.2546;\ 0.1819;\ \dots`$ Только при этих исключительных значениях
появляется особая прямая $`a_1\sin 2\omega + a_2 \sin 6\omega = \varepsilon A \omega`$.

#### Как это сделано в программе

Случаи выше в коде отдельно не прописаны. Функция `singular_lines` перебирает точки $`\omega_k = k\pi/4`$ из
рассматриваемого диапазона, численно проверяет совместность вырожденной системы и возвращает получившиеся прямые.
Совпадающие прямые и прямую $`\lambda = 0`$ она отбрасывает. На графиках особые прямые показаны серым пунктиром;
при переходе через них $`N`$ меняется на 2 (уходит пара $`\pm i\omega_k`$).

Например, при $`\varepsilon = 0.5`$, $`A = 0`$ (картинка `results/partition_eps=0.5_A=0.png`) программа находит 4 прямые:
$`a_1 + a_2 = 0.3831;\ 1.4674;\ -4.5517;\ 8.8696`$. Это ровно $`m = 1, \dots, 4`$ по формуле выше.

Заметим также, что при $`A = 0`$ сам трёхчлен $`\varepsilon^2\lambda^2 + 1`$ имеет корни $`\pm i/\varepsilon`$, поэтому точка
$`(0, 0)`$ лежит на границе, а ромб из п. 7.3 вырождается ($`m(0) = 0`$). Подробнее — в п. 7.5.

### 4.2. Сколько $`\omega`$ нужно перебрать

Из системы $`|R + iI| = |a_1 e^{-2i\omega} + a_2 e^{-6i\omega}| \le |a_1| + |a_2|`$. В окне $`|a_1|, |a_2| \le 3`$
имеем $`|a_1| + |a_2| \le L = 6`$, а $`|R| = \varepsilon^2\omega^2 - 1 > L`$ при $`\omega > \sqrt{1 + L}/\varepsilon`$.
Значит, при больших $`\omega`$ точек кривой в окне нет, и достаточно $`\omega \in (0, \sqrt{1+L}/\varepsilon + 1]`$
(функция `omega_max`). При $`\varepsilon = 0.5`$ это $`\omega \le 6.29`$ — **9 ветвей** кривой.

## 5. Штриховка: куда уходят корни

Пусть при $`a = (a_1, a_2)`$ у $`P`$ есть простой корень $`\lambda = i\omega`$. Продифференцируем тождество
$`P(\lambda(a), a) = 0`$:

```math
P'(\lambda)\,d\lambda + e^{-2\lambda}da_1 + e^{-6\lambda}da_2 = 0
\;\Rightarrow\;
d\lambda = -\frac{e^{-2i\omega}da_1 + e^{-6i\omega}da_2}{P'(i\omega)},
```

```math
P'(\lambda) = 2\varepsilon^2\lambda + \varepsilon A - 2a_1e^{-2\lambda} - 6a_2e^{-6\lambda}.
```

Тогда $`\mathrm{Re}\,d\lambda = g_1\,da_1 + g_2\,da_2`$, где

```math
g_1 = \mathrm{Re}\left(-\frac{e^{-2i\omega}}{P'(i\omega)}\right),\qquad
g_2 = \mathrm{Re}\left(-\frac{e^{-6i\omega}}{P'(i\omega)}\right).
```

Сдвиг в направлении вектора $`g`$ переводит корень в правую полуплоскость. Сравнивая $`g`$ с левой нормалью
$`(-\dot a_2, \dot a_1)`$ к кривой (движемся в сторону роста $`\omega`$), определяем, слева или справа штриховать ветвь
(функции `crossing_direction` и `hatch_side`). Переход через D-кривую на заштрихованную сторону **увеличивает
$`N`$ на 2** (уходит пара $`\pm i\omega`$). Это классическое правило Неймарка, только знак вычисляется не по
определителю вручную, а прямо по производной корня.

## 6. Подсчёт числа корней $`N`$ в каждой точке

Чтобы подписать каждую область (а не только найти одну устойчивую), считаем $`N`$ на сетке $`301 \times 301`$
по **принципу аргумента** (функция `count_unstable_roots`).

Для квазиполинома запаздывающего типа со старшим членом степени $`n`$ без корней на мнимой оси

```math
\Delta_{\omega: 0 \to +\infty} \arg P(i\omega) = \pi\left(\frac n2 - N\right).
```

У нас $`n = 2`$, поэтому

```math
\boxed{\;N = 1 - \frac{1}{\pi}\,\Delta_{0}^{+\infty}\arg P(i\omega)\;}
```

Проверка: при $`a_1 = a_2 = 0`$ получаем $`1 - \varepsilon^2\omega^2 + i\varepsilon A\omega`$, аргумент растёт от $`0`$ до
$`\pi`$, $`N = 0`$ — квадратный трёхчлен устойчив при $`A > 0`$.

Как считается бесконечный «хвост». При $`\omega > \Omega = \sqrt{1 + L}/\varepsilon`$

```math
\mathrm{Re}\,P(i\omega) \le 1 - \varepsilon^2\omega^2 + |a_1| + |a_2| < 0,
```

т.е. $`P(i\omega)`$ остаётся в левой полуплоскости, а $`\arg P(i\omega) \to \pi`$. Значит, приращение на
$`[\Omega, +\infty)`$ равно повороту от $`\arg P(i\Omega)`$ до ближайшего $`\pi`$ — это добавляется аналитически.
На $`[0, \Omega]`$ аргумент суммируется по малым шагам $`\Delta\omega = 0.02`$ (за шаг самый быстрый множитель
$`e^{-6i\omega}`$ поворачивается лишь на $`0.12`$ рад).

**Независимые проверки:**

* в нескольких точках $`N`$ пересчитан контурным интегралом $`\frac{1}{2\pi}\oint d\arg P`$ по границе полукруга
  радиуса 40 в правой полуплоскости — значения совпали ($`0, 0, 3, 4, 0, 2`$ в точках $`(0,0)`$, $`(0.5,0.3)`$,
  $`(-2,0)`$, $`(2,2)`$, $`(-0.5,-0.2)`$, $`(1.5,-1)`$ при $`\varepsilon = 0.5`$);
* $`N`$, найденное численно, везде согласуется со штриховкой: через D-кривую оно меняется на 2, через прямую
  $`\lambda = 0`$ — на 1 (см. графики);
* при уменьшении шага $`\Delta\omega`$ в 4 раза результаты практически не меняются (отличаются лишь единичные узлы сетки у самых границ).

### 7.3. Гарантированный ромб устойчивости (для всех $`\varepsilon > 0`$)

Положим $`x = \varepsilon\omega`$. Тогда при $`\lambda = i\omega`$

```math
|\varepsilon^2\lambda^2 + \varepsilon A\lambda + 1| = |1 - x^2 + iAx| \ge m(A) := \min_{x \ge 0}|1 - x^2 + iAx|,
\qquad
|a_1e^{-2i\omega} + a_2 e^{-6i\omega}| \le |a_1| + |a_2|.
```

Значит, при $`|a_1| + |a_2| < m(A)`$ корней на мнимой оси нет **ни при каком** $`\varepsilon > 0`$ (и $`P(0) \ne 0`$,
так как $`m(A) \le 1`$). Ромб связен и содержит устойчивую точку $`(0,0)`$, поэтому целиком лежит в области
устойчивости. Минимизируя $`f(u) = (1-u)^2 + A^2u`$, $`u = x^2`$:

```math
m(A) =
\begin{cases}
A\sqrt{1 - A^2/4}, & 0 < A < \sqrt 2,\\
1, & A \ge \sqrt 2,
\end{cases}
\qquad m(1) = \frac{\sqrt 3}{2} \approx 0.866 .
```

На графиках это пунктирный ромб (функция `guaranteed_radius`).

### 7.4. Что происходит при $`\varepsilon \to 0`$

![Эволюция](results/evolution_A=1.png)

Границы области устойчивости на осях:

| $`\varepsilon`$ | $`a_1`$ при $`a_2 = 0`$ | $`a_2`$ при $`a_1 = 0`$ |
|---|---|---|
| 1 | $`[-1.000;\ 0.917]`$ | $`[-0.891;\ 0.919]`$ |
| 0.5 | $`[-1.000;\ 0.878]`$ | $`[-0.909;\ 0.868]`$ |
| 0.25 | $`[-0.867;\ 0.946]`$ | $`[-0.869;\ 0.875]`$ |
| 0.1 | $`[-0.879;\ 0.867]`$ | $`[-0.868;\ 0.868]`$ |

* С уменьшением $`\varepsilon`$ D-кривых в окне становится всё больше (ветви идут с шагом $`\pi/4`$ по $`\omega`$,
  а $`\omega`$ нужно перебирать до $`\sim 1/\varepsilon`$), они густо заполняют плоскость, а область устойчивости
  **сжимается к ромбу** $`|a_1| + |a_2| < m(A)`$: вершины стремятся к $`0.866`$.
  Причина — на частотах $`\omega = x/\varepsilon`$ множители $`e^{-2i\omega}`$, $`e^{-6i\omega}`$ вращаются очень быстро
  и «пробегают» все фазы, так что оценка из п. 7.3 становится точной в вершинах.
* **Предельный случай $`\varepsilon = 0`$ — сингулярный.** Уравнение вырождается в разностное
  $`1 + a_1e^{-2\lambda} + a_2 e^{-6\lambda} = 0`$. Заменой $`z = e^{-2\lambda}`$ получаем $`1 + a_1 z + a_2 z^3 = 0`$,
  а $`\mathrm{Re}\,\lambda < 0 \Leftrightarrow |z| > 1`$; для $`w = 1/z`$: все корни $`w^3 + a_1 w^2 + a_2 = 0`$ должны
  лежать в круге $`|w| < 1`$ (условие Шура–Кона; в программе — собственные числа сопровождающей матрицы,
  функция `stable_mask_limit`). Эта область (правая нижняя панель) **не является пределом** областей при
  $`\varepsilon \to 0`$: например, точка $`(a_1, a_2) = (1, -0.4)`$ устойчива при $`\varepsilon = 0`$, но при
  $`\varepsilon > 0`$ неустойчива, причём число неустойчивых корней растёт как $`1/\varepsilon`$:

  | $`\varepsilon`$ | 1 | 0.5 | 0.25 | 0.1 | 0.05 | 0.02 |
  |---|---|---|---|---|---|---|
  | $`N`$ в точке $`(1, -0.4)`$ | 2 | 2 | 4 | 6 | 12 | 32 |

  Поэтому при малых $`\varepsilon`$ нельзя просто «отбросить» члены $`\varepsilon^2\lambda^2 + \varepsilon A\lambda`$ —
  правильной оценкой области устойчивости служит ромб $`|a_1| + |a_2| < m(A)`$.

### 7.5. Случаи $`A = 0`$ и $`A < 0`$

Оба случая проверены отдельно: в точках, которые программа считает устойчивыми, $`N`$ пересчитано независимым
контурным интегралом по полукругу радиуса 60 в правой полуплоскости, и результаты совпали.

| $`\varepsilon`$ | $`A`$ | точка $`(a_1, a_2)`$ | $`N`$ (программа) | $`N`$ (контурный интеграл) |
|---|---|---|---|---|
| 0.5 | 0 | $`(0.3,\ 0)`$ | 0 | 0 |
| 0.5 | 0 | $`(0,\ 0.2)`$ | 2 | 2 |
| 0.5 | −0.1 | $`(0.18,\ 0.09)`$ | 0 | 0 |
| 0.5 | −0.1 | $`(0,\ 0)`$ | 2 | 2 |
| 1 | −0.5 | $`(-0.7,\ -0.23)`$ | 0 | 0 |
| 1 | −0.5 | $`(0,\ 0)`$ | 2 | 2 |

#### Почему при $`A = 0`$ область маленькая и нет ромба

При $`A = 0`$ и $`a_1 = a_2 = 0`$ уравнение $`\varepsilon^2\lambda^2 + 1 = 0`$ описывает осциллятор **без трения**: его корни
$`\pm i/\varepsilon`$ лежат прямо на мнимой оси. Поэтому начало координат лежит на D-кривой (она проходит через
$`(0, 0)`$ при $`\omega = 1/\varepsilon`$), а ромб из п. 7.3 вырождается в точку: $`m(0) = 0`$.

Устойчивость может дать только само запаздывание. Подставим в формулу из п. 5 корень $`\lambda = i/\varepsilon`$
и $`P'(i/\varepsilon) = 2i\varepsilon`$. При малых $`a_1, a_2`$ получим

```math
\mathrm{Re}\,d\lambda = \frac{a_1\sin(2/\varepsilon) + a_2\sin(6/\varepsilon)}{2\varepsilon} .
```

Значит, корни уходят влево только с одной стороны от прямой $`a_1\sin(2/\varepsilon) + a_2\sin(6/\varepsilon) = 0`$.
Остальные ветви D-кривой (другие частоты) быстро ограничивают эту полуплоскость. В итоге область устойчивости —
узкий «клин» с вершиной в начале координат. При $`\varepsilon = 0.5`$ это $`a_1 \in [0;\ 0.68]`$,
$`a_2 \in [-0.28;\ 0.24]`$, площадь около $`0.11`$. Сторона клина зависит от знаков $`\sin(2/\varepsilon)`$ и
$`\sin(6/\varepsilon)`$, поэтому при изменении $`\varepsilon`$ клин поворачивается. При $`\varepsilon \to 0`$ он
стягивается в точку — в согласии с п. 7.4, где предельная область равна ромбу радиуса $`m(0) = 0`$.

#### Почему при $`A < 0`$ устойчивости почти нет

При $`A < 0`$ и $`a_1 = a_2 = 0`$ оба корня трёхчлена лежат в правой полуплоскости (их сумма $`-A/\varepsilon > 0`$),
то есть «трение» отрицательное и колебания раскачиваются. Чтобы система стала устойчивой, запаздывающие слагаемые
должны погасить эту раскачку. По формуле выше они сдвигают корни на величину порядка $`|a|`$. Если $`|A|`$ мало,
этого хватает, и клин из случая $`A = 0`$ по непрерывности сохраняется: для квазиполинома запаздывающего типа
открытая область устойчивости не исчезает при малом изменении коэффициентов. С ростом $`|A|`$ клин сужается и
пропадает.

Итак, утверждение «при $`A < 0`$ области устойчивости нет» верно только начиная с некоторого порога $`A^*(\varepsilon)`$.
Площадь области устойчивости в окне $`a_1 \in [-1;\ 1.5]`$, $`a_2 \in [-1;\ 1]`$ (для $`\varepsilon = 0.5`$ дополнительно
просмотрено окно $`[-10;\ 10]^2`$ — других устойчивых областей там нет):

| $`\varepsilon`$ \ $`A`$ | 0 | −0.05 | −0.1 | −0.15 | −0.2 | −0.3 | −0.5 |
|---|---|---|---|---|---|---|---|
| 1 | 0.614 | 0.523 | 0.438 | 0.359 | 0.286 | 0.158 | 0.023 |
| 0.5 | 0.108 | 0.052 | 0.023 | 0.008 | 0.001 | 0 | 0 |
| 0.25 | 0.103 | 0.049 | 0.021 | 0.007 | 0.001 | 0 | 0 |
| 0.1 | 0.009 | 0.0003 | 0 | 0 | 0 | 0 | 0 |

Отсюда пороги: $`A^*(1) \in (-0.7;\ -0.6)`$, $`A^*(0.5) \in (-0.25;\ -0.22)`$. При $`\varepsilon = 0.1`$
устойчивость пропадает уже при $`A \approx -0.1`$, т.е. при малых $`\varepsilon`$ порог приближается к нулю. Например, при $`\varepsilon = 0.5`$, $`A = -1`$ (это значение и проверялось) в окне $`[-10;\ 10]^2`$
нет ни одной устойчивой точки, везде $`N \ge 2`$. А вот при $`\varepsilon = 1`$, $`A = -0.5`$ маленькая область
устойчивости есть: $`a_1 \in [-0.80;\ -0.62]`$, $`a_2 \in [-0.32;\ -0.16]`$.

## 8. Тройные точки D-кривой и тройная бифуркация Андронова–Хопфа

### 8.1. Что ищем

Каждая точка D-кривой отвечает паре чисто мнимых корней $`\pm i\omega`$. Точка пересечения двух ветвей
(с частотами $`\omega_1 \ne \omega_2`$) отвечает **двум** парам $`\pm i\omega_1`$, $`\pm i\omega_2`$ — это точка двойной бифуркации
Хопфа. На плоскости $`(a_1, a_2)`$ такие точки встречаются «в общем положении»: именно они образуют углы области
устойчивости на графиках из п. 7.

Нас интересует более редкий случай: **три** ветви D-кривой с частотами $`\omega_1 < \omega_2 < \omega_3`$ проходят через одну
точку $`(a_1^*, a_2^*)`$. Тогда у $`P(\lambda)`$ одновременно шесть корней на мнимой оси:

```math
P(\pm i\omega_1) = P(\pm i\omega_2) = P(\pm i\omega_3) = 0 .
```

Если при этом точка лежит **на границе области устойчивости**, то все остальные корни находятся в левой полуплоскости,
и это критический случай **тройной бифуркации Андронова–Хопфа**. Именно в окрестности таких точек у нелинейной
задачи возникают сложные автоколебательные режимы (см. п. 8.7).

Почему для этого нужно подбирать $`\varepsilon`$. Условие «пара $`\pm i\omega`$ на оси» — это одно условие на параметры
(коразмерность 1: кривая на плоскости). Две пары — коразмерность 2 (точка на плоскости). Три пары — коразмерность 3:
на плоскости $`(a_1, a_2)`$ при произвольных $`\varepsilon`$ и $`A`$ таких точек нет, нужен третий параметр. Мы фиксируем $`A = 1`$
и используем в качестве третьего параметра $`\varepsilon`$: тройная точка появляется только при отдельных значениях
$`\varepsilon = \varepsilon^*`$.

### 8.2. Уравнения

Обозначим через $`a(\omega; \varepsilon) = \bigl(a_1(\omega), a_2(\omega)\bigr)`$ точку D-кривой из п. 4. Тройная точка — это решение
системы

```math
a(\omega_1; \varepsilon) = a(\omega_2; \varepsilon) = a(\omega_3; \varepsilon),
```

то есть **4 уравнения** (по две координаты в двух равенствах) на **4 неизвестных** $`\omega_1, \omega_2, \omega_3, \varepsilon`$.
Число уравнений совпадает с числом неизвестных — поэтому решения изолированы, что и согласуется с подсчётом
коразмерности выше. Найденная точка $`(a_1^*, a_2^*) = a(\omega_1; \varepsilon^*)`$.

### 8.3. Как искали

1. **Сканирование по $`\varepsilon`$.** Для $`\varepsilon`$ от 1 до 0.18 с шагом 0.005 строим ветви D-кривой в квадрате
   $`|a_1|, |a_2| \le 2`$ и находим все попарные пересечения ветвей (пересечения ломаных). Пересечение считаем **углом
   области устойчивости**, если на окружности радиуса 0.004 вокруг него есть точка с $`N = 0`$.
2. **Признак тройной точки.** Граница области устойчивости — это рёбра вдоль ветвей D-кривой, соединённые углами.
   Когда при изменении $`\varepsilon`$ какое-то ребро (вдоль частоты $`\omega_b`$) стягивается в точку, два соседних угла
   $`(\omega_a, \omega_b)`$ и $`(\omega_b, \omega_c)`$ сливаются — в момент слияния через точку проходят три ветви $`\omega_a, \omega_b, \omega_c`$.
   Поэтому ищем пары углов с общей частотой, расстояние между которыми стремится к нулю.
3. **Уточнение методом Ньютона.** Приближение со сканирования уточняем методом Ньютона для системы из п. 8.2
   (матрица Якоби — центральными разностями). Метод сходится за несколько итераций, невязка — порядка $`10^{-14}`$.

### 8.4. Основной результат

При $`A = 1`$ наибольшее найденное значение $`\varepsilon`$ (в диапазоне $`[0.18;\ 1]`$) с тройной точкой на границе устойчивости:

```math
\varepsilon^* \approx 0.4407427110, \qquad (a_1^*, a_2^*) \approx (-0.0884058287,\ 0.9472748912),
```

```math
\omega_1 \approx 0.4735045882, \qquad \omega_2 \approx 1.4427464187, \qquad \omega_3 \approx 2.3446076604 .
```

![Тройная точка](results/triple_point.png)

На картинке — окрестность точки при трёх значениях $`\varepsilon`$ (серым — область устойчивости $`N = 0`$, цветом — три ветви
D-кривой, на которых лежат частоты $`\omega_1, \omega_2, \omega_3`$):

* **$`\varepsilon = 0.452 > \varepsilon^*`$.** Верхняя часть области устойчивости ограничена тремя ветвями: у неё есть короткое ребро
  вдоль синей ветви ($`\omega_1`$) между двумя углами — точками двойного Хопфа $`(\omega_1, \omega_3)`$ и $`(\omega_1, \omega_2)`$.
* **$`\varepsilon = \varepsilon^*`$.** Ребро вдоль $`\omega_1`$ стянулось в точку: все три ветви проходят через вершину области
  устойчивости. Это и есть тройная точка.
* **$`\varepsilon = 0.43 < \varepsilon^*`$.** Синяя ветвь ушла с границы (прошла выше вершины), область устойчивости ограничена
  уже только двумя ветвями $`\omega_2`$ и $`\omega_3`$, а синяя ветвь отделяет области $`N = 2`$ и $`N = 4`$.

Три прямые через одну точку делят её окрестность на **шесть секторов**. Обходя точку, получаем числа неустойчивых
корней $`N = 0, 2, 4, 6, 4, 2`$: каждое пересечение ветви добавляет или убирает пару корней, и напротив сектора
устойчивости лежит сектор, где неустойчивы сразу все три пары ($`N = 6`$).

```math
\frac{\partial(\mathrm{Re}\,\lambda_1, \mathrm{Re}\,\lambda_2, \mathrm{Re}\,\lambda_3)}{\partial(a_1, a_2, \varepsilon)} \approx
\begin{pmatrix}
-0.0541 & 0.1608 & 0.0094\\
\phantom{-}0.1373 & 0.1602 & 0.0399\\
-0.1479 & 0.1476 & -0.3425
\end{pmatrix},
\qquad \det \approx 0.0103 \ne 0 .
```

неустойчивой. Значит, параметры $`(a_1, a_2, \varepsilon)`$ дают полную трёхпараметрическую развёртку тройного Хопфа.

### 8.7. Что это значит для автоколебаний

Характеристическое уравнение описывает только **линеаризацию** задачи, поэтому сами бифуркации определяются
нелинейными слагаемыми исходного уравнения. Линейный анализ даёт следующее.

**Центральное многообразие.** В точке $`(a_1^*, a_2^*, \varepsilon^*)`$ оно шестимерно: на нём живут три колебательные моды с
частотами $`\omega_1, \omega_2, \omega_3`$, а все остальные моды затухают не медленнее $`e^{-0.109\,t}`$. Поэтому вблизи этой точки
поведение решений с малыми амплитудами сводится к системе из шести уравнений (для трёх комплексных амплитуд $`z_k`$).

**Нормальная форма.** В нерезонансном случае уравнения для модулей $`\rho_k = |z_k|`$ имеют вид

```math
\dot\rho_k = \rho_k\Bigl(\mu_k + \sum_{j=1}^{3} c_{kj}\,\rho_j^2\Bigr) + \dots, \qquad k = 1, 2, 3,
```

где $`\mu_k = \mathrm{Re}\,\lambda_k`$ — линейные функции отклонения $`(a_1 - a_1^*,\ a_2 - a_2^*,\ \varepsilon - \varepsilon^*)`$ (их коэффициенты —
строки матрицы из п. 8.5), а коэффициенты $`c_{kj}`$ определяются нелинейностью задачи. Благодаря невырожденности
матрицы из п. 8.5 три числа $`\mu_1, \mu_2, \mu_3`$ можно выбирать независимо, т.е. попасть в любой из восьми октантов
$`(\pm, \pm, \pm)`$: на плоскости $`(a_1, a_2)`$ это шесть секторов из п. 8.4, а оставшиеся комбинации получаются сдвигом по $`\varepsilon`$.

**Какие режимы возможны.** Ненулевые положения равновесия этой системы — автоколебательные режимы исходной задачи:

* **циклы** — одна ненулевая амплитуда, колебания с одной частотой $`\approx \omega_k`$;
* **двумерные торы** — две ненулевые амплитуды, квазипериодические колебания с двумя частотами;
* **трёхмерный тор** — все три амплитуды ненулевые, трёхчастотные колебания.

Какие из них рождаются и какие устойчивы, зависит от знаков и величин $`c_{kj}`$. Кроме того, трёхмерная система для
амплитуд сама может иметь периодические и хаотические решения, а трёхчастотный тор при возмущении может разрушаться —
это классический путь к хаосу (сценарий Рюэля–Такенса–Ньюхауса). Поэтому окрестность тройной точки — естественное
место для поиска сложных автоколебательных бифуркаций.

**Близкие резонансы.** У основной точки $`\omega_1 : \omega_2 : \omega_3 \approx 1 : 3.05 : 4.95`$, т.е. частоты близки к резонансу
$`1 : 3 : 5`$: $`3\omega_1 - \omega_2 \approx 0.022`$, $`5\omega_1 - \omega_3 \approx 0.023`$. Точного резонанса нет, но при такой малой расстройке в
нормальной форме нужно сохранить и резонансные слагаемые. Для соотношения $`3\omega_1 \approx \omega_2`$ это слагаемые третьего
порядка: $`z_1^3`$ в уравнении для $`z_2`$ и $`\bar z_1^2 z_2`$ в уравнении для $`z_1`$. Они связывают фазы мод и могут приводить к захвату
частот (синхронизации) на торах.

### 8.8. Ограничения

* $`A = 1`$ фиксировано; при другом $`A`$ значения $`\varepsilon^*`$ и точки другие (скрипт легко пересчитать).
* Просканирован диапазон $`\varepsilon \in [0.18;\ 1]`$ с шагом 0.005. События с очень коротким существованием ребра (меньше шага)
  могли быть пропущены, а при $`\varepsilon < 0.18`$ поиск не проводился.
* Учитывались только углы, образованные двумя ветвями D-кривой; тройные точки с участием прямой $`\lambda = 0`$ (корень $`\lambda = 0`$
  и две пары $`\pm i\omega`$) — это другой тип вырождения, здесь они не искались.
* Выводы о бифуркациях в п. 8.7 качественные: для конкретной нелинейной задачи коэффициенты $`c_{kj}`$ нужно вычислять отдельно.

| `equation.py` | $`P(\lambda)`$, $`P'(\lambda)`$, прямая $`\lambda = 0`$, формулы D-кривой, направление ухода корня, $`m(A)`$ |
| `partition.py` | ветви D-кривой и штриховка, особые прямые, $`N`$ по принципу аргумента, случай $`\varepsilon = 0`$, поиск связных областей для подписей |
| `draw.py` | главный график D-разбиения и сравнительный график по $`\varepsilon`$ |
| `main.py` | печать расчётов в консоль, построение и сохранение графиков |
| `triple.py` | поиск, уточнение и проверка тройных точек D-кривой (п. 8), картинка `results/triple_point.png` |

Алгоритм:

1. Строим ветви D-кривой $`a(\omega)`$ между нулями $`\sin 4\omega`$ и прямую $`1 + a_1 + a_2 = 0`$.
2. Для каждой ветви находим сторону штриховки по знаку $`\mathrm{Re}\,d\lambda`$.
3. На сетке считаем $`N(a_1, a_2)`$ по принципу аргумента (векторно, numpy).
4. Красим области по $`N`$ (зелёный — устойчивость, от светлого к тёмно-красному — рост $`N`$), ищем связные
   компоненты и подписываем $`N`$ в самой «глубокой» точке каждой.
5. Повторяем для набора $`\varepsilon`$ и сравниваем области устойчивости; для $`\varepsilon = 0`$ — критерий Шура–Кона.

Время работы с параметрами по умолчанию — около 10 секунд. Число шагов по $`\omega`$ растёт как $`1/\varepsilon`$,
поэтому для главного графика $`\varepsilon`$ ограничено снизу значением `EPS_MIN = 0.01` (при $`\varepsilon = 0.01`$
программа работает около 40 секунд). Точки сетки обрабатываются порциями, так что память не растёт с уменьшением
$`\varepsilon`$.

## 10. Выводы

* Границы D-разбиения: прямая $`1 + a_1 + a_2 = 0`$ и D-кривая
  $`a_1 = \dfrac{(\varepsilon^2\omega^2-1)\sin 6\omega - \varepsilon A\omega\cos 6\omega}{\sin 4\omega}`$,
  $`a_2 = \dfrac{\varepsilon A\omega\cos 2\omega - (\varepsilon^2\omega^2-1)\sin 2\omega}{\sin 4\omega}`$.
* Область устойчивости — единственная область с $`N = 0`$, она содержит начало координат. При $`A = 1`$:
  для $`\varepsilon = 1`$ это $`a_1 \in [-1.74;\ 1.26]`$, $`a_2 \in [-0.94;\ 1.04]`$; для $`\varepsilon = 0.5`$ —
  $`a_1 \in [-1.08;\ 0.86]`$, $`a_2 \in [-0.92;\ 0.94]`$.
* При любом $`\varepsilon \in (0, 1]`$ гарантированно устойчив ромб $`|a_1| + |a_2| < m(A)`$
  ($`m(1) = \sqrt3/2`$), и при $`\varepsilon \to 0`$ область устойчивости к нему сжимается.
* Предел $`\varepsilon = 0`$ сингулярен: область устойчивости разностного уравнения шире и не совпадает
  с пределом областей при $`\varepsilon \to 0`$.
* При $`A = 0`$ начало координат лежит на границе. Устойчивость обеспечивается только запаздыванием, и область
  устойчивости — небольшой клин с вершиной в $`(0, 0)`$.
* При $`A < 0`$ область устойчивости есть только при $`A > A^*(\varepsilon)`$, где $`A^*(1) \approx -0.65`$,
  $`A^*(0.5) \approx -0.23`$; при меньших $`A`$ (например, $`A = -1`$) устойчивых точек нет.
* При $`A = 1`$ и $`\varepsilon^* \approx 0.4407427`$ три ветви D-кривой проходят через одну точку границы устойчивости
  $`(a_1^*, a_2^*) \approx (-0.0884,\ 0.9473)`$: у квазиполинома три пары простых корней $`\pm i\omega_k`$, $`\omega \approx 0.4735;\ 1.4427;\ 2.3446`$,
  остальные корни левее $`\mathrm{Re}\,\lambda = -0.109`$. Это критический случай тройной бифуркации Андронова–Хопфа с
  невырожденной трёхпараметрической развёрткой по $`(a_1, a_2, \varepsilon)`$. При $`\varepsilon \in [0.18;\ 1]`$ найдено ещё четыре
  такие точки (п. 8.6), но у них рядом с мнимой осью есть дополнительные слабо затухающие моды.
