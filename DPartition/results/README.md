# Результаты

## Содержание

* **partition_eps=0.5_A=1.png**: D-разбиение плоскости (a₁, a₂) при ε = 0.5, A = 1 (параметры по умолчанию).
* **partition_eps=1_A=1.png**: D-разбиение плоскости (a₁, a₂) при ε = 1, A = 1.
* **partition_eps=0.5_A=0.png**: D-разбиение при ε = 0.5, A = 0 (видны особые прямые a₁ + a₂ = const).
* **partition_eps=1_A=-0.5.png**: D-разбиение при ε = 1, A = −0.5 (маленькая область устойчивости при отрицательном A).
* **evolution_A=1.png**: области устойчивости при ε = 1; 0.5; 0.25; 0.1; 0.05 и в предельном случае ε = 0.
* **evolution_A=0.png**: то же сравнение по ε при A = 0.
